# 智芯萌伴（ZZPET-BOT）

> 基于 STM32F103 与 ESP32-S3 的 AI 陪伴机器人项目展示。

## 项目简介

智芯萌伴是一款面向儿童陪伴与编程启蒙场景的机器人原型。系统采用双 MCU 架构：

- **STM32F103**：负责运动控制、舵机步态与传感器数据采集等实时任务。
- **ESP32-S3**：负责 Wi-Fi / 蓝牙通信、语音与 AI 交互等联网任务。

项目围绕“陪伴、探索、启蒙”设计，支持通过传感器和外设扩展交互能力。

## 系统架构

```text
传感器 / 舵机 / 外设
        │
        ▼
 STM32F103（实时控制）
        │ 串口通信
        ▼
 ESP32-S3（AI 交互与联网）
        │
        ▼
语音交互 / 移动端 / 云端服务
```
