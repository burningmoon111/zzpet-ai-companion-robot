# 硬件概览

## 控制架构

| 模块 | 主要职责 |
| --- | --- |
| STM32F103 | 实时运动控制、舵机步态与传感器数据采集 |
| ESP32-S3 | Wi-Fi / 蓝牙连接、语音与 AI 交互、上层通信 |
| 舵机与外设 | 机器人动作执行与扩展交互 |
| 传感器 | 触摸、温度等环境或交互数据采集 |

两个 MCU 通过串口完成控制指令与状态信息交换。
