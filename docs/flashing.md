# 预编译固件刷写说明

> 原始源码尚未公开。本说明仅用于已确认硬件兼容性的项目成员或具备嵌入式刷写经验的使用者。

## 前置检查

1. 确认开发板为项目对应的 ESP32-S3 硬件配置。
2. 使用稳定数据线连接电脑，避免刷写过程中断电。
3. 下载固件后，按 [`firmware-status.md`](firmware-status.md) 核对 SHA-256 校验值。
4. 记录原设备的固件版本，以便故障排查或回退。

## 风险提示

错误的固件、分区表或烧录地址可能导致设备无法启动。若你并非项目成员，或没有完整的硬件接线信息，请不要直接刷写。
